Grammar help

Grammar help for this lesson

can / can I

Can For Ability And Permission

Use I can for ability. Use Can I...? to ask if something is okay.

You say what you can do or ask permission in a simple way.

Common mistake

After can, use the base verb: can swim, not can swims.

  • I can swim. Can I use this seat?
日本語で見る

I can は「できること」、Can I...? は「してもいいですか」と聞く時に使います。

Practice this grammar

instructions

Basic Imperatives

Give a short instruction. Start with the action word: Open, Wait, Listen, or Do not run.

You give classroom directions, safety instructions, or simple steps.

Common mistake

Do not add you before a normal imperative. Say Please wait, not You please wait.

  • Open the door. Please wait here.
日本語で見る

短い指示を出す形です。Open, Wait, Listen, Do not run のように動詞から始めます。
