    Grammar words
    request

    Asking someone to give something or do something.

    何かをもらう、または何かをしてもらうために頼むことです。

    verb

    An action word, like go, eat, have, or wait.

    go, eat, have, wait のような動作を表す言葉です。

    I'd like | Could I | Can I | Would you like

    Meaning

    Use soft phrases like Could I...? and I would like... to ask for help, food, tickets, or information.

    日本語で見る

    Because / So / When

    A2 · practical

    Use because for a reason, so for a result, and when for time.

    日本語で見る

    because は理由、so は結果、when は時間をつなぐ時に使います。

    Grammar words
    conjunction

    A joining word, like and, but, or or.

    and, but, or のように、言葉や文をつなぐ言葉です。

    reason

    Why something happens. Because often gives a reason.

    なぜそうなるかを表します。because は理由を言う時によく使います。

    result

    What happens because of something. So often gives a result.

    そのために何が起こるかを表します。so は結果を言う時によく使います。

    time

    When something happens.

    いつ起こるかを表します。

    Size And Fit Language

    A2 · practical

    Use too big or too small to explain a fit problem, then ask for one size up or down.

    日本語で見る

    サイズが合わない時は too big / too small と言い、one size up/down で次のサイズを頼みます。

    Grammar words
    adjective

    A describing word, like big, small, new, or busy.

    big, small, new, busy のように、様子を説明する言葉です。

    comparative

    A comparison between two things, like bigger or more useful.

    2つを比べる形です。bigger や more useful などです。

    too big | too small | one size up | one size down

    Meaning

    Use too big or too small to explain a fit problem, then ask for one size up or down.

    日本語で見る

    サイズが合わない時は too big / too small と言い、one size up/down で次のサイズを頼みます。

    Shape

    too + adjective; one size up/down

    Example

    Common mistake
