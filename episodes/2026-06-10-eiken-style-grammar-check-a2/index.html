    A2 · core

    Because gives the reason. So gives the result.

    日本語で見る

    because は理由、so は結果を表します。

    Grammar words
    result

    What happens because of a reason.

    理由があって起きることです。

    because | so

    because and so

    Because gives the reason. So gives the result.

    日本語で見る

    because は理由、so は結果を表します。

    Example

    It was raining, so we took a taxi. / I went to bed early because I was tired.

    "It was raining, so we took a taxi."

    Use because for a reason and so for a result.

    polite request

    A soft way to ask someone to do something.

    相手に丁寧にお願いする言い方です。
