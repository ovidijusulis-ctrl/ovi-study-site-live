Lesson

Part 1: Check the Return Policy First

Maria bought a blue Uniqlo jacket last Saturday. At home, she saw a small hole near the pocket. Before going back, she checked her receipt and the current return policy. Uniqlo Japan says a normal store return is usually within 30 days. An item with a problem must be checked by a store. Each store can have different rules and exceptions. Maria puts the jacket, receipt, and tags in the bag.

Lesson

Part 2: Talk to the Worker Politely

At the store, Maria looked for a return counter. If there was no return counter, she could ask a cashier. She said, "Excuse me. I would like to return this jacket, please." The worker asked, "What is the problem?" Maria answered, "There is a small hole near the pocket. I bought it last Saturday." She showed the jacket and the receipt. She was calm and clear. This process works in many clothes stores. Ask at the return counter or cashier. Say that you want to return the item. Explain the problem in one short sentence.

Lesson

Part 3: Ask for a Refund

The worker checked the jacket, the receipt, and the current policy. She said, "This return can be refunded to the card you used." Maria said, "A refund to my card, please." The worker asked, "Can I see the card you used?" Maria gave her the same card. The worker said, "Your bank may need time to return the money. Please keep the return receipt. If it takes longer than you expect, check the store's policy." Maria said, "Thank you. Can I have the return receipt?" The worker gave it to her.

What you can do now

Summary

Check the current return policy because each store can have different rules. Keep the receipt and tags, and ask what else you need.

At the return counter or cashier, start politely: "Excuse me. I would like to return this, please."

Say the problem in one short sentence and ask what refund method is available.

Your bank may need time to return the money. Keep the return receipt and check the store's policy if needed.
