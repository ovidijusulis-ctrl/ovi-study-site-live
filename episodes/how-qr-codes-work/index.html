Reading

Part 1 — What Is a QR Code?

A QR code is a two-dimensional pattern of black and white squares. The letters QR stand for Quick Response.

Unlike a barcode, which only stores information in one direction (left to right), a QR code stores information in two directions — across and down. This means it can hold much more data in a small space. For example, a single QR code can store a full website address, a phone number, or even a short message.

Sample answer

Reading

Part 2 — Modules and Size

The small black and white squares inside a QR code are called modules. Every module is either black or white, and together they form a code.

A simple QR code — for example, one that stores just a short word — needs fewer modules and is smaller. A complex QR code — for example, one that stores a long web address — needs more modules and becomes larger. The more data you put in, the bigger the code gets.

Check — Modules and Size

1. Why does a QR code get bigger when it stores more data?

Sample answer

Because more data needs more modules. A larger QR code contains more black and white squares to hold all the extra information.

Reading

Part 3 — How Your Phone Reads a QR Code

Look at a QR code and you will notice three square shapes in three corners. These are called position patterns.

They help your phone's camera find the code and understand which direction it is facing — even if the code is upside down or tilted. Once the camera locates the three corner squares, it reads the modules across and down and turns the pattern into data. This is why scanning is so fast: the position patterns act like a map.

Check — Position Patterns

1. What do the three corner squares in a QR code do?

Sample answer

They are position patterns. They help the camera find the code and know which direction it is facing, making scanning fast even if the code is tilted or upside down.

Reading

Part 4 — What Happens When a QR Code Is Damaged?

A QR code has a built-in safety feature called error correction. This means that even if part of the code is dirty, torn, or covered, some missing data can still be restored and read correctly.

The code stores extra information that helps rebuild some missing pieces automatically. This is why a QR code may still work when a small part is hard to see.

Check — Error Correction

1. Why can a QR code still work when part of it is covered by a logo?

Sample answer

Because QR codes have error correction. The code stores extra copies of the data, so missing or covered parts can be rebuilt and read correctly.

Reading

Part 5 — Staying Safe When You Scan

QR codes are useful, but they can also open harmful or fake websites. Scammers may use a QR code to send you to a page that tries to steal your personal information.

Before you open a link, always check the web address on your screen. If the address looks strange, the code is unexpected, or it pressures you to act quickly, do not open it.
